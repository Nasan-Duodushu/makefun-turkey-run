Featherweight Fugitive — a top-down stealth-escape game: a turkey escapes becoming Thanksgiving dinner. The farmer patrols, gets suspicious, chases and searches; his carving knives fly and the kitchen oven blasts. Hide in the hay, eat corn, grab feathers, and run the farmyard, the barn and the kitchen to reach the back door — 1,500 metres to the forest. Keyboard (WASD/arrows) or mouse click-to-move, synthesized sound, three stages, title and end screens with restart.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
